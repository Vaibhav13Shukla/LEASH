## Hard submission gate

Before pushing, run Foundry in a supported Docker/WSL 2 environment:

```bash
foundryctl cast -f casting.yaml
git add casting.yaml.lock
```

`casting.yaml.lock` is generated by Foundry. Do not forge, hand-edit, or fabricate it. The hackathon requires the generated file so judges can reproduce the SigNoz deployment.

## Pre-push commands

```powershell
$env:PYTHONPATH = "."
.\.venv\Scripts\python.exe -m pytest -q
docker compose --env-file .env.example -f docker-compose.app.yml config --quiet
git status --short
```

## Create and push a branch

```powershell
git switch -c codex/leash-autonomy-error-budget
git add .dockerignore .env.example .gitignore PRODUCT.md README.md Dockerfile docker-compose.app.yml casting.yaml casting.yaml.lock requirements.txt services tests web scripts docs
git commit -m "Build LEASH autonomy error budget gateway"
git remote add origin https://github.com/YOUR_GITHUB_USERNAME/leash.git
git push -u origin codex/leash-autonomy-error-budget
```

If the repository already has an `origin`, do not run `git remote add origin`; inspect it with:

```powershell
git remote -v
```

# Product

## Register

product

## Users

Solo founders and platform engineers supervising autonomous release agents. Their immediate task is to see whether an agent has retained enough observed reliability to perform a risky action.

## Product Purpose

LEASH converts observed downstream agent reliability into enforceable tool permissions. Success is a live, reproducible proof that a SigNoz alert changes agent policy and blocks a subsequent destructive request.

## Brand Personality

Calm, forensic, decisive.

## Anti-references

Avoid cyberpunk control-room theater, fake terminal output, generic AI chat, decorative metric cards, and dashboards that imitate SigNoz instead of linking to real SigNoz evidence.

## Design Principles

1. Evidence before assertion.
2. State changes must be legible in one glance.
3. Dangerous actions look dangerous, never exciting.
4. Preserve the trace from intent to enforcement.
5. Make the control loop comprehensible to a non-SRE judge.

## Accessibility & Inclusion

Meet WCAG AA contrast, use semantic controls and keyboard focus states, never convey status with color alone, and honor reduced-motion preferences.
